# Estimation_Bias_Aim3
This experiment code is part of Aim 3 of my dissertation. 
The purpose of this study is to determine whether math anxiety influences the ability to gauge math performance,
and to determine whether feedback helps correct biases in math performance.

This code consists of 12 blocks of math multiplication problems, with varying levels of difficulty (Easy, Medium, Hard). 
Participants will receive performance feedback on half the blocks but not the other half, and this will be randomly determined.

At the end of each block, participants will self-report their current level of motivation, anxiety, and estimates of their own performance
